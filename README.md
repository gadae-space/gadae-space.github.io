# 가대 공간 어디가지 🐑

가톨릭대학교 성심교정의 공부·휴식 공간 정보를 한곳에 모은 웹사이트입니다.
키스톤디자인 10분반 2조 풀어조 팀 프로젝트입니다.

🔗 사이트: https://yeowonchoi41.github.io/gadae-space/

## 왜 만들었나요

교내 공간 정보는 홈페이지, 도서관 앱, 공지, 현장 안내문에 흩어져 있습니다.
그래서 "멘사 주말에 몇 시까지 열어요?", "여기서 밥 먹어도 돼요?" 같은 질문이 에브리타임에 계속 올라옵니다.
재학생 127명에게 설문한 결과, 62%가 "자주 쓰는 몇 군데만 안다"고 답했고, 91.3%가 이런 서비스가 있으면 쓰겠다고 답했습니다.

이 사이트는 실시간 빈자리를 보여주는 서비스가 아닙니다.
흩어진 운영시간과 이용 규칙을 모아서, 지금 갈 수 있는 곳을 바로 알 수 있게 하는 것이 목표입니다.

## 할 수 있는 것

- 지금 이용 가능한 곳 표시: 현재 시각과 학사일정(학기 중·시험기간·방학·공휴일)을 기준으로 계산합니다.
- 다른 시간 미리 보기: "시험기간 평일 밤 10시"처럼 원하는 시간을 골라볼 수 있습니다.
- 상황별 추천: 혼자 집중, 팀플 회의, 밥 먹을 곳, 지금 학식, 밤늦게까지, 바로 앉기
- 조건 고르기: 정숙·대화 가능, 콘센트, 예약·발권 없이, 음식 가능 등
- 미니 캠퍼스: 건물을 누르면 양이 그 건물로 이동하고, 그 건물의 공간만 보여줍니다.
- 공간별 상세 정보: 운영시간표, 출입·이용 방법, 좌석, 콘센트, 음식 규칙, 출처와 확인 날짜

현재 7개 건물, 27개 공간을 담고 있습니다.
(학생미래인재관 · 중앙도서관 · 김수환관 · 안드레아관 · 니콜스관 · 밤비노관 · 비르투스관)

## 폴더 구조

```
index.html          사이트 전체 (HTML · CSS · JS 한 파일)
images/
  A/ B/ BA/ K/ L/ N/ V/   건물별 공간 사진 (파일 이름 = 공간 id)
  sheep/                  양 캐릭터 그림
```

빌드 과정이 없는 정적 사이트라서 GitHub Pages에 그대로 올리면 동작합니다.

## 정보 수정하는 법

모든 데이터는 `index.html`의 `<script>` 윗부분에 있습니다.

| 고칠 것 | 위치 |
|---|---|
| 학기·시험기간·방학 날짜 | `PERIODS` |
| 공휴일 | `HOLIDAYS` |
| 설문 링크 · 오류 제보 메일 | `SURVEY`, `CONTACT_EMAIL` |
| 건물 | `GROUPS` |
| 공간 정보 | `PLACES` |
| 사진 연결 | `HAS_PHOTO`에 공간 id 추가 → `images/건물폴더/공간id.jpg` |

운영시간은 이렇게 적습니다.

```js
hours: {
  semester: hrs("09:00-21:00", X, X, X),   // 평일, 토, 일, 공휴일
  exam:     exSame("06:00-23:00"),          // 시험기간: 매일 같음
  vacation: same(X),                        // 방학: 매일 휴무
}
```

- `"09:00-21:00"`: 한 구간 / `"중식 11:30-14:00 / 석식 17:30-19:00"`: 여러 구간
- `X`: 휴무, `U`: 아직 확인 안 됨(화면에 '–'), `H24`: 24시간
- `"05:00-01:00"`처럼 자정을 넘기면 다음 날 새벽까지로 계산합니다.
